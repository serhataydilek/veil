# Offline

Show a small local banner such as **Offline** or **Unable to reach Veil**. It refers only to this device’s connection and never names or infers peer connectivity. Existing valid local content remains usable; text composition may remain available only where bounded encrypted queue policy permits.

Do not predict when a peer will receive a message or turn retry/queue behavior into peer status. The banner is calm, dismissible only if the condition remains discoverable, and accessible without color alone.
