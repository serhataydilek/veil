# Onboarding

Keep onboarding to three focused states; do not request personal data or notification permission here.

1. **Welcome:** `Veil` / `Private conversations. Nothing else.` Primary action: **Continue**.
2. **Device-owned identity:** explain: “Your identity lives on this device. There is no phone, email, password, or recovery service. Losing this identity can permanently remove access.” Also state messages expire automatically and both people must exchange current IDs. Primary action: **Create identity**.
3. **Creation:** non-account progress state, then `Identity ready.` Continue directly to Home. Failure returns to a local creation error without creating a replacement or exposing key material.

Do not collect name, photo, birthday, email, phone, or username. Use Create identity, never create account/sign in/restore. Notification permission is asked later, after contextual explanation.
