# Add ID and Saved IDs

## Add ID

Title: **Add an ID**. Explain: “Both people need to add each other’s current IDs before a conversation can begin.” Provide manual grouped-ID entry, paste, and Scan ID only. Primary action: **Save ID**.

After local validation and saving, show `ID saved`. Do not say request sent, waiting, user found, pending, or sent to a user. Format/checksum failure is an explicit local error; remotely meaningfulness is never exposed. QR scan follows the same local parse/save outcome.

## Saved IDs

Saved IDs live under Add ID rather than Home. Each entry contains only an abbreviated local capability, locally verifiable expiry if known, and delete. It has no avatar, remote validity, waiting indication, activity, or peer status. Expired or deleted entries disappear from this local list under lifecycle policy.
