# My ID

The default screen presents the current rotating contact ID in grouped monospace, with locally known rotation/expiry information such as `Changes in 4 days`. Actions are **Copy**, **Share**, and **Show QR**. A secondary action is **Create one-time ID**.

Explain: “Someone knowing your ID is not enough to start a conversation. You must also add their current ID.” Do not expose stable identity keys, fingerprints, device data, mailbox/session identifiers, or any relationship state. Copy/share is capability handling, not profile publication.
