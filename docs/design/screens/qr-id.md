# Temporary QR

QR renders only the current short-lived pairing capability. It may show a precise local expiry timer—for example `Expires in 09:32`—because QR’s short lifetime makes it actionable. Offer brightness helper and **Close/Revoke**; no stable identity material appears in the code or surrounding UI.

The scan surface is titled **Scan ID**, offers the manual-entry alternative, and after valid local parsing reports only `ID saved`. It never announces a user lookup, remote validity, or pairing result.
