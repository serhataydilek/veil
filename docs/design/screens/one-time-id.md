# One-time ID

Show the temporary one-time capability with locally known expiry and the explanation: “Expires after one successful connection or when its time limit ends.” Actions are **Copy**, **Show QR**, and **Revoke**.

No waiting/connection status is shown. When consumed, expired, or revoked, display `This ID is no longer usable.` That outcome does not identify who used it unless a separate authenticated conversation was established. The lifecycle remains governed by the reviewed-rendezvous requirement; this screen does not imply it is implemented.
