# Verify identity

Title: **Verify identity**. Present a safety code and optional QR comparison with: “Compare this code with the other person through another trusted channel or in person.” A deliberate **Mark verified** action records local verification state.

The surface names a private-conversation identity check, never account verification. It does not claim the other person is safe, prove real-world identity, or reveal their public profile. An identity change resets local verification and returns the conversation to its paused trust state.
